# RetroUID13Modern - 通信管理ツール 仕様書

Windows 95/98/2000 時代のレトロな業務系通信ツール（`RetroUIFull`）をベースに、Delphi 13 (Unicode / Windows Modern VCLスタイル) にてモダンなUIデザインへと全面刷新したデモ・シミュレーションアプリケーションです。

---

## 1. プロジェクト概要

- **プロジェクト名**: `RetroUID13Modern`
- **プロジェクトファイル**: `RetroUID13Modern.dproj` / `RetroUID13Modern.dpr`
- **対象プラットフォーム**: Windows (Win32 / Win64 / WinARM64EC)
- **開発環境**: Embarcadero RAD Studio 13 / Delphi
- **適用スタイル**: `Windows Modern` (`Vcl.Styles`)
- **システムフォント**: `Yu Gothic UI` (9pt / 12pt / 15pt / 20pt)

---

## 2. モダン化（脱レトロUI）における変更点

1. **半角カナの完全排除**:
   - レトロUI特有の「ｼﾘｱﾙ ﾎﾟｰﾄ」「ﾊﾟﾘﾃｨ ﾁｪｯｸ」「ﾛｸﾞを保存する」「ﾌﾙｽｸﾘｰﾝ表示」などの半角カナ表記をすべて全角日本語（「シリアルポート」「パリティチェック」「ログを保存する」「フルスクリーン表示にする」）へ統一。
2. **レトロ原色カラーリングの廃止**:
   - 背景の濃紺（`clNavy`）、黄色（`clYellow`）、蛍光緑（`clLime`）、原色シアン等の派手な原色指定を撤廃。
   - VCLスタイル「Windows Modern」のカラーパレット（オフホワイト、落ち着いたグレー、プライマリブルー）に調和する現代的でクリーンな配色を採用。
3. **古臭い立体ベベル（Bevel）表現の撤廃**:
   - `TBevel` やパネルの立体縁取り（`bvRaised` / `bvLowered`）による凹凸装飾を廃止し、フラットなパネルおよびグループボックス構成に変更。
4. **現代のスクリーン環境に合わせたゆとりのあるレイアウト**:
   - 従来の 400x406 ピクセルの狭小レイアウトから、現代のディスプレイで自然に見やすい 640x680 ピクセルへと拡張。
   - コントロール間のマージンやパディングを十分に確保し、余白のあるモダンなUIを実現。
5. **最新デザインガイドラインへの準拠**:
   - 主要アクションボタン（[実行(&E)]）にプライマリブルーのフォーカスカラーを適用。
   - 送信ログ領域はダークテーマのターミナル風配色（`Consolas` 等幅フォント）を採用し、可読性と実用性を両立。

## 3. 画面レイアウトおよび各部仕様

### 3.1 タイトル部 (`pnlTitle`: TPanel)
- フラットパネルヘッダー（`Color = 16250871` / `#F7F7F7`）。
- 大きなタイトル見出し「通信管理ツール」（20pt 太字）およびサブタイトル「Ver 1.00」を表示。

### 3.2 通信方式 (`grpHoushiki`: TGroupBox)
ラジオボタンで通信方式を選択。方式に応じて「ポート詳細」の初期値や動作ログが切り替わります。
1. **シリアルポート(&S)** (`rbSerial`):
   - ポート: `COM1`
   - 通信速度: 9600, 19200, 38400, 115200 bps
   - パリティチェック: 有効/無効 切替可能
   - 送信ログ: シリアル通信コマンド（例: `> TX: [ENQ] データ要求`、`> RX: [ACK] ポート応答`）
2. **モデム(&M)** (`rbModem`):
   - ポート: `COM3 (MODEM)`
   - 通信速度: 9600, 19200, 38400, 115200 bps
   - パリティチェック: 有効/無効 切替可能
   - 送信ログ: ATコマンド（例: `> ATDT 03-3501-XXXX`、`> CONNECT 28800/V.34`）
3. **LAN 接続(&L)** (`rbLan`):
   - ポート: `192.168.1.10:8080` (IPアドレス:ポート形式)
   - 通信速度: 自動認識（無効化）
   - パリティチェック: 無効化（グレーアウト）
   - 送信ログ: ソケット通信（例: `> TCP: SYN_SENT -> 192.168.1.100`、`> TCP: ESTABLISHED ポート:8080`）

※通信実行中は誤操作防止のため、通信方式・ポート詳細の各項目は無効化（グレーアウト）されます。

### 3.3 オプション設定 (`grpOption`: TGroupBox)
各チェックボックスにより動作オプションを制御します。
- **自動的に再接続する (`chkAuto`)**:
  - 有効時、通信実行中に低確率で擬似的な回線瞬断が発生し、数秒後に自動復帰する演出を行います。
- **ログを保存する (`chkLog`)**:
  - チェックを入れると、チェックボックスの右隣に **[開く(&O)]** ボタンが出現します。
  - [開く] ボタンをクリックすると、保存されたログテキストファイル（`retroui_modern.log`）を標準のエディタで開きます。
  - チェックを外すと [開く] ボタンは非表示になります。
- **警告音を鳴らす (`chkWarn`)**:
  - 有効時、エラー演出、中止確認、通信瞬断発生時などに Windows システム警告音（ビープ音）を鳴らします。
- **フルスクリーン表示にする (`chkFull`)**:
  - チェックを入れるとウィンドウが最大化され、チェックを外すと通常サイズ（640x680）に復帰します。

### 3.4 送信ログ領域 (`lstLog`: TListBox)
- 送信ログはダークテーマ配色（背景色: 濃紺/黒系 `2499877`、文字色: 明るいグレー、フォント: `Consolas` 10pt）。
- 常に領域内に収まる最新の 6 行を表示。新しい行が追加されると最古の行を自動消去して流れるように表示します。
- 「ログを保存する」が有効な場合、画面上で流れて消えた行も含め、全ログ履歴がファイルへ記録されます。

### 3.5 信号状態 (`prgStatus`: TProgressBar)
- **待機中**: `0%`（プログレスバー空）
- **実行中**: `50%` 〜 `98%` の範囲でタイマーによりリアルに増減。
- 瞬断発生時は一時的に急低下（`10%`）し、再接続成功で復帰します。

### 3.6 ステータスバー (`statusBar`: TStatusBar)
下部の 3 分割パネルで現在の状態を表示します。
- **パネル 1**: `準備完了` / `ステータス: 正常` / `ステータス: 切断`
- **パネル 2**: `通信状態: 停止中` / `通信状態: 通信中` / `通信状態: 再接続中`
- **パネル 3**: 実行経過時間を `経過時間 HH:MM:SS` 形式でリアルタイムにカウントアップ。

### 3.7 アクションボタン群 (`pnlButtons`: TPanel)
- **[ヘルプ(&H)]** (`btnHelp`): アプリケーションのバージョン情報、各オプションの説明ダイアログを表示。
- **[中止(&C)]** (`btnStop`): 通信実行中にクリック可能。「通信を中止しますか？」の確認ダイアログを表示。
- **[実行(&E)]** (`btnExec`): 通信シミュレーションを開始（デフォルトボタン・プライマリ青アクセント）。
- **[閉じる(&X)]** (`btnClose`): 通信実行中または待機時の終了確認ダイアログを表示。

---

## 4. ビルド・実行方法

1. Embarcadero RAD Studio で `RetroUI.groupproj` または `RetroUID13Modern.dproj` を開きます。
2. ターゲットプラットフォームに `Windows 32-bit`（または `Windows 64-bit`）を選択します。
3. `Shift + F9` または `Project -> Build RetroUID13Modern` でビルドします。
4. `Win32\Debug\RetroUID13Modern.exe` が生成されます。
