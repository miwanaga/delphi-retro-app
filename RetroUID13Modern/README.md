# RetroUIFull - 通信管理 ツール 仕様書

Windows 95/98/2000 時代のレトロな業務系通信ユーティリティを再現したデモ・シミュレーションアプリケーションです。

---

## 1. 概要
- **プロジェクト名**: `RetroUIFull`
- **対象プラットフォーム**: Windows (VCL Application)
- **開発環境**: Embarcadero RAD Studio / Delphi

本アプリケーションはモック（デモ）ですが、ユーザーの操作や各種オプション設定に応じてリアルタイムに挙動・表示が変化するシミュレーション機能を備えています。

---

## 2. 画面構成およびコントロール仕様

### 2.1 タイトル部
- **タイトルパネル (`pnlTitle`)**: 濃紺（`clNavy`）背景に黄色文字（`clYellow`）で「■ 通信監視 ■」を表示。

### 2.2 通信方式 (`grpHoushiki`)
ラジオボタンで通信方式を選択。方式に応じて「ポート詳細」の初期値や動作ログが切り替わります。
1. **ｼﾘｱﾙ ﾎﾟｰﾄ (`rbSerial`)**:
   - ﾎﾟｰﾄ: `COM1`
   - 通信速度: 9600, 19200, 38400, 115200 bps
   - ﾊﾟﾘﾃｨ ﾁｪｯｸ: 有効/無効 切替可能
   - 送信ログ: シリアル通信コマンド（例: `> TX: [ENQ] ... [ACK] OK (38400bps)`）
2. **ﾓﾃﾞﾑ (`rbModem`)**:
   - ﾎﾟｰﾄ: `COM3 (MODEM)`
   - 通信速度: 14400, 28800, 33600, 56000 bps
   - ﾊﾟﾘﾃｨ ﾁｪｯｸ: 有効/無効 切替可能
   - 送信ログ: ATコマンド（例: `> ATDT 03-XXXX-XXXX ... CONNECT 28800/V.34`）
3. **LAN 接続 (`rbLan`)**:
   - ﾎﾟｰﾄ: `192.168.1.10:8080` (IPアドレス:ポート形式)
   - 通信速度: 自動認識 (`10/100Mbps (AUTO)`)
   - ﾊﾟﾘﾃｨ ﾁｪｯｸ: 無効化（グレーアウト）
   - 送信ログ: ソケット通信（例: `> TCP: SYN_SENT -> ESTABLISHED 192.168.1.100:8080`）

※通信実行中は誤操作防止のため、通信方式・ポート詳細の各項目は無効化（グレーアウト）されます。

---

### 2.3 オプション設定 (`grpOption`)
各チェックボックスにより動作オプションを制御します。
- **自動再接続する (`chkAuto`)**:
  - 有効時、通信実行中に低確率で擬似的な回線瞬断が発生し、数秒後に自動復帰する演出を行います。
- **ﾛｸﾞを保存する (`chkLog`)**:
  - チェックを入れると、チェックボックスの右隣に **[開く(&O)]** ボタンが出現します。
  - [開く] ボタンをクリックすると、保存されたログテキストファイル（`retroui_full.log`）を標準の関連付けエディタ（メモ帳など）で開きます。
  - チェックを外すと [開く] ボタンは非表示になります。
- **警告音を鳴らす (`chkWarn`)**:
  - 有効時、エラー演出、中止確認、通信瞬断発生時などに Windows システム警告音（ビープ音）を鳴らします。
- **ﾌﾙｽｸﾘｰﾝ表示 (`chkFull`)**:
  - チェックを入れるとウィンドウが最大化され、チェックを外すと通常サイズ（400x406）に復帰します。

---

### 2.4 送信ログ領域 (`lstLog`)
- スクロールバーは **非表示** とし、領域内（4行程度）に収まる最新ログのみを表示します。
- 新しいログ行が追加されて領域からはみ出る場合、**古い先頭行を自動的に破棄** します（常に最新数行が領域内に収まって流れる演出）。
- 「ﾛｸﾞを保存する」が有効な場合、画面上で流れて消えた行も含め、全ログ履歴がファイルへ記録されます。

---

### 2.5 信号状況 (`prgStatus`)
- **未実行（待機中）時**: `0%`（プログレスバー空）
- **実行中**: `45%` 〜 `98%` の範囲でタイマーによりリアルに増減。
- 瞬断発生時は一時的に急低下（`10%〜20%`）し、再接続成功で復帰します。

---

### 2.6 ステータスバー (`pnlStatus`)
下部の3分割パネルで現在の状態を表示します。
- **パネル1 (`pnlStat1`)**:
  - 待機中: ` ｽﾃｰﾀｽ 待機中`（銀色/灰色）
  - 実行中: ` ｽﾃｰﾀｽ 正常`（黄緑色 `clLime`）
  - 瞬断時: ` ｽﾃｰﾀｽ 警告`（赤色 `clRed`）
- **パネル2 (`pnlStat2`)**:
  - 待機中: ` ﾓｰﾄﾞ:ｱｲﾄﾞﾙ`（黄色 `clYellow`）
  - 実行中: ` ﾓｰﾄﾞ:通信中`（水色 `clAqua`）
  - 中止時: ` ﾓｰﾄﾞ:停止`（灰色）
- **パネル3 (`pnlStat3`)**:
  - 実行経過時間を `HH:MM:SS` 形式でリアルタイムにカウントアップ。
  - 停止時にリセットまたは停止時間で固定。

---

### 2.7 コントロールボタン
- **実行(&E)** (`btnExec`):
  - 通信シミュレーションを開始。
  - 「実行」ボタン無効化、「中止」ボタン有効化。
- **中止(&C)** (`btnStop`):
  - 通信実行中にクリック可能。
  - 「通信を中止しますか？」の確認ダイアログを表示（OKで停止、キャンセルで継続）。
- **ﾍﾙﾌﾟ(&H)** (`btnHelp`):
  - アプリケーションのバージョン情報、各オプションの説明、キーボードショートカットを案内するレトロ風ダイアログを表示。
- **閉じる(&X)** (`btnClose`) および ウィンドウの [×] ボタン:
  - 通信実行中: 「通信中ですが終了しますか？」と警告ダイアログを表示。
  - 待機中: 「終了しますか？」の確認ダイアログを表示。
  - OK押下でアプリケーションを終了。
