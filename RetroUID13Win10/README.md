# RetroUID13Win10 - 通信管理ツール 仕様書

Windows 10 / Windows 11 向けのモダンコントロール群（`Vcl.WinXCtrls`）を採用し、Delphi 13 (Unicode / Windows Modern VCLスタイル) にて構築した現代的な通信ユーティリティのデモ・シミュレーションアプリケーションです。

---

## 1. プロジェクト概要

- **プロジェクト名**: `RetroUID13Win10`
- **プロジェクトファイル**: `RetroUID13Win10.dproj` / `RetroUID13Win10.dpr`
- **対象プラットフォーム**: Windows (Win32 / Win64 / WinARM64EC)
- **開発環境**: Embarcadero RAD Studio 13 / Delphi
- **適用スタイル**: `Windows Modern` (`Vcl.Styles`)
- **システムフォント**: `Yu Gothic UI` (9pt / 12pt / 15pt / 20pt)

本プロジェクトは、`RetroUID13Modern` で実現したレイアウト刷新・配色適正化・脱レトロUIをベースに、Windows 10/11 で標準導入されたモダンコントロール群を取り入れることで、さらなる操作性と視認性の向上を図ったプロジェクトです。

---

## 2. Windows 10/11 モダンコントロール群への置き換え仕様

| コントロール名 | Delphi クラス | 従来のコントロール | 置き換えの目的と仕様 |
| :--- | :--- | :--- | :--- |
| **タイトルパネル** | `TRelativePanel` (`pnlTitle`) | `TPanel` | コントロール相互の相対配置を可能にする Win10 レイアウトパネル。ヘッダーの整理と将来的なレスポンシブ拡張に対応。 |
| **ポート入力** | `TSearchBox` (`edtPort`) | `TEdit` | 虫眼鏡アイコンを内蔵した検索ボックス型エディット。ポートやホストの視覚的な入力・選択UIを提供。 |
| **パリティチェック** | `TToggleSwitch` (`swParity`) | `TCheckBox` | スライダ式のオン/オフトグルスイッチ。パリティ検査の有効/無効を直感的に切り替え。 |
| **自動再接続** | `TToggleSwitch` (`swAuto`) | `TCheckBox` | デフォルト「オン」。瞬断時の自動リカバリ機能を明瞭に提示。 |
| **ログ保存** | `TToggleSwitch` (`swLog`) | `TCheckBox` | 「オン」にすると右隣に `[開く(&O)]` ボタンが動的に出現。 |
| **警告音** | `TToggleSwitch` (`swWarn`) | `TCheckBox` | デフォルト「オン」。システム警告音の有効/無効を制御。 |
| **フルスクリーン** | `TToggleSwitch` (`swFull`) | `TCheckBox` | ウィンドウの最大化 / 通常表示をトグル切替。 |
| **通信中インジケータ** | `TActivityIndicator` (`actIndicator`) | *(なし)* | 「信号状態」ラベル横に配置。通信実行中に `aitSectorRing`（セクターリング）形状で回転アニメーションをリアルタイム表示。 |

## 3. 画面レイアウトおよび各部仕様

### 3.1 ヘッダー部 (`pnlTitle`: TRelativePanel)
- フラットデザインの背景（`Color = 16250871` / `#F7F7F7` 近似）に、濃いグレーのタイトル文字（20pt 太字）とバージョン表記「Ver 1.00 (Win10)」を配置。

### 3.2 通信方式グループ (`grpHoushiki`: TGroupBox)
ラジオボタンにより通信インターフェースを選択（通信実行中は安全のためグレーアウト）：
1. **シリアルポート(&S)** (`rbSerial`): 初期ポート `COM1`、速度変更可、パリティ変更可
2. **モデム(&M)** (`rbModem`): 初期ポート `COM3 (MODEM)`、速度変更可、パリティ変更可
3. **LAN 接続(&L)** (`rbLan`): 初期ポート `192.168.1.10:8080`、速度・パリティは自動設定のため無効化

### 3.3 ポート詳細グループ (`grpPort`: TGroupBox)
- ポート名 (`edtPort`: `TSearchBox`): 選択された方式に応じたポート・アドレスを表示。
- 速度 (`cmbBaud`: `TComboBox`): 9600 / 19200 / 38400 / 115200 を選択（ドロップダウンリスト形式）。
- パリティチェック (`swParity`: `TToggleSwitch`): オン/オフのトグルスイッチ。

### 3.4 オプション設定グループ (`grpOption`: TGroupBox)
- 各種動作設定を 4 つの `TToggleSwitch` で整理配置。
  - **自動的に再接続**: 通信中の擬似瞬断発生時に自動リカバリをシミュレート。
  - **ログを保存**: `retroui_win10.log` へのログ自動追記。オンのときのみ `btnOpenLog` (`[開く(&O)]`) が表示される。
  - **警告音を鳴らす**: 確認ダイアログや警告時のビープ音を制御。
  - **フルスクリーン表示**: ウィンドウ最大化の切り替え。

### 3.5 送信ログ領域 (`lstLog`: TListBox)
- 送信ログはダークテーマ配色（背景色: 濃紺/黒系 `2499877`、文字色: 明るいグレー、フォント: `Consolas` 10pt）。
- 常に最新の 6 行を表示し、行数上限を超えた場合は最古の行を自動消去してスムーズにログが流れる演出。

### 3.6 信号状態 & アクティビティ表示
- **プログレスバー (`prgStatus`: TProgressBar)**: 実行中に通信シグナルレベル（50%〜98%）をリアルタイムにシミュレート。
- **アクティビティインジケータ (`actIndicator`: TActivityIndicator)**: 通信実行中にアニメーション開始（`Animate := True`）、停止時に自動停止。

### 3.7 アクションボタン群 (`pnlButtons`: TPanel)
- **[ヘルプ(&H)]**: システム情報や各オプション説明を表示。
- **[中止(&C)]**: 通信実行中に有効化。確認メッセージを経て待機状態へ遷移。
- **[実行(&E)]**: デフォルトボタン（プライマリカラー・青アクセント）。通信シミュレーションを開始。
- **[閉じる(&X)]**: アプリケーションの安全な終了確認を実施。

### 3.8 ステータスバー (`statusBar`: TStatusBar)
下部に 3 パネルを配置：
1. **動作状態**: `準備完了` / `ステータス: 正常` / `ステータス: 切断`
2. **通信状況**: `通信状態: 停止中` / `通信状態: 通信中` / `通信状態: 再接続中`
3. **経過時間**: `経過時間 HH:MM:SS`（タイマー連動）

## 4. ビルド・実行方法

1. Embarcadero RAD Studio で `RetroUI.groupproj` または `RetroUID13Win10.dproj` を開きます。
2. ターゲットプラットフォームに `Windows 32-bit`（または `Windows 64-bit`）を選択します。
3. `Shift + F9` または `Project -> Build RetroUID13Win10` でビルドします。
4. `Win32\Debug\RetroUID13Win10.exe` が生成されます。
